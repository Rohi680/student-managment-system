# Student Management System

A beginner-friendly Student Management System developed using Python and SQLite.

## About the Project
This project helps manage student information through a simple menu-driven application.

## Technologies Used
- Python
- SQLite
- SQL

## Features
1. Add Student
2. View All Students
3. Search Student
4. Update Student Details
5. Delete Student
6. Exit Application

## How to Run
1. Install Python.
2. Download the student.py file.
3. Open the terminal.
4. Run the following command:

```bash
python student.py
```

## Database
SQLite is used to store student records.
